# 🎬 IMDb Movie Review Sentiment Analysis

An end-to-end Natural Language Processing (NLP) pipeline built in Python to perform binary sentiment classification on IMDb movie reviews — predicting whether an audience review is **positive** or **negative**.

---

## 📌 Overview

Movie reviews contain unstructured, highly subjective feedback. This project processes raw text from the IMDb reviews dataset, applies text cleaning and vectorization techniques, and trains machine learning models to detect sentiment accurately.

### Key Highlights
- **Text Preprocessing:** Tokenization, stopword removal, lowercasing, and text cleaning.
- **Feature Extraction:** TF-IDF / Bag of Words vectorization.
- **Modeling:** Supervised classification comparing baseline and ML classifiers.
- **Evaluation:** Performance tracked using Accuracy, Precision, Recall, and F1-score.
